# Study Planner

Planificateur de révisions avec compte à rebours d'examen, Pomodoro, sessions d'étude, lecteur de musique, ambiances sonores et notes.

## Fonctionnalités
- Compte à rebours vers la date d'examen (choisie dans l'interface)
- Pomodoro : focus, pause courte, pause longue (toutes les 4 sessions), durées réglables, démarrage auto, bip + notification
- Sessions d'étude par jour avec progression et emploi du temps hebdomadaire
- Lecteur de musique (fichiers locaux ou URL) et ambiances (pluie, orage, océan, vent)
- Notes avec sauvegarde automatique
- Données sauvegardées dans le navigateur (localStorage)

## Lancer
Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages.

## Structure
- `index.html` : structure
- `style.css` : design
- `script.js` : logique
